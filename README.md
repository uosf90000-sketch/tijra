# تِجرا — TIJRA

منصة عربية لإدارة تشغيل التاجر الصغير من مكان واحد: المخزون، المبيعات، الموردون، المشتريات الذكية، المحاسبة، الموظفون والرواتب.

## حدود المنتج المعتمدة

- **لا يوجد تمويل أو إقراض** داخل تِجرا.
- **التوصيل ليس جزءًا من المنصة**؛ ترتيبات التوصيل وموعده تبقى مباشرة بين التاجر والمورد.
- المحاسبة ضمن المنتج.
- إدارة الموظفين والرواتب ضمن المنتج.
- تِجرا يساعد التاجر على معرفة ماذا يطلب، وكم يطلب، ومن أي مورد بناءً على الأسعار المسجلة وحركة المخزون.

## ما تم بناؤه في الـMVP

- Dashboard عربي RTL ومتجاوب.
- شاشة مخزون كثيفة وواضحة مع حالة الصنف والتغطية والتكلفة والهامش.
- شاشة موردين مع مقارنة أسعار مسجلة.
- شاشة مشتريات ذكية واقتراح الكميات وتقسيم الطلبات.
- شاشة مطابقة فاتورة/استلام تكشف فرق الكمية أو السعر قبل تحديث المخزون.
- شاشة مبيعات/POS نموذجية توضح خصم المخزون من البيع.
- شاشة محاسبة مبسطة: مبيعات، تكلفة بضاعة، مصاريف، رواتب وصافي ربح تقديري.
- إدارة موظفين ورواتب ومسيرات.
- Onboarding للمنشأة.
- API لحساب خطة الشراء.
- API لحساب الرواتب.
- Prisma schema يغطي التشغيل الأساسي وحركات المخزون والفواتير والمسيرات.

## الواجهة

الواجهة مستلهمة من أنماط dashboards الحديثة في 21st.dev: هرم بصري واضح، sidebar مجمّع، جداول كثيفة للبيانات، بطاقات KPI محدودة، mobile bottom navigation، وحالات واضحة للمخزون والطلبات. الكود والتصميم خاصان بـTIJRA وليس نسخًا مباشرًا من مكوّن بعينه.

## التشغيل محليًا

```bash
npm install
cp .env.example .env
npm run db:generate
npm run dev
```

ثم افتح `http://localhost:3000`.

## الفحص

```bash
npm run check
```

## API

### `POST /api/purchase-plan`

يستقبل الأصناف، المخزون الحالي، متوسط البيع اليومي وعروض الموردين، ويرجع كمية الشراء المقترحة وأفضل عرض مسجل.

### `POST /api/payroll/calculate`

يحسب الإجمالي والخصومات والسلف وصافي الراتب لكل موظف ومسير الرواتب ككل.

### `GET /api/health`

Health check بسيط يوضح الوحدات الموجودة وحدود المنتج.

## المرحلة التالية قبل الإنتاج

الواجهات الحالية مكتملة كنواة MVP، لكن الإنتاج الحقيقي يحتاج توصيلها بقاعدة PostgreSQL الفعلية، تنفيذ المصادقة والصلاحيات، معاملات DB ذرّية للبيع والاستلام، OCR فعلي لفواتير الموردين، اختبارات E2E، وربط الفوترة الإلكترونية عند اعتماد نطاقها التنظيمي.

لا تضع مفاتيح API أو كلمات المرور أو بيانات الإنتاج داخل المستودع العام. استخدم متغيرات البيئة فقط.
