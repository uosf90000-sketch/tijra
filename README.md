# تِجرا | TIJRA

منصة عربية ذكية لإدارة تجارة المحلات الصغيرة: المخزون، الموردون والمشتريات، المحاسبة، الموظفون والرواتب، والمشتريات الذكية.

## الفكرة

تِجرا لا تريد أن تكون مجرد برنامج محاسبة أو نقطة بيع. الهدف هو إغلاق دورة العمل الأساسية للتاجر:

**بيع → نقص مخزون → توقع الاحتياج → مقارنة الموردين → طلب شراء → استلام ومطابقة → تحديث المخزون → تحديث الربح والحسابات.**

## نطاق الـMVP

- إدارة المنتجات والمخزون والتنبيهات.
- الموردون وأسعار الأصناف وطلبات الشراء.
- اقتراح الكميات المطلوبة ومقارنة الموردين.
- تسجيل المبيعات والمصاريف وحساب تكلفة البضاعة والأرباح.
- الموظفون والرواتب والبدلات والخصومات والسلف.
- واجهة عربية RTL وموجهة للجوال أولًا.

## خارج النطاق

- **التمويل:** غير موجود في المنتج.
- **التوصيل:** تِجرا لا تدير التوصيل؛ يبقى الاتفاق والتنفيذ بين التاجر والمورد.
- **امتلاك المخزون أو المستودعات:** تِجرا منصة تشغيل وربط وليست موزعًا للبضائع.

## التقنية المبدئية

- Next.js + React + TypeScript
- PostgreSQL + Prisma
- بنية بسيطة قابلة للنشر على Railway
- طبقة AI ستضاف بعد تثبيت دورة المخزون والمشتريات الأساسية
