# مدار — التصنيع وأوامر الإنتاج (قاعدة تشغيلية تجريبية)

## ما نُفّذ برمجيًا
- قوائم تصنيع ManufacturingBom مرتبطة بالمنتج النهائي ومكونات المواد الخام، مع فصل الشركة والتحقق من وجود الأصناف ومنع التكرار واستهلاك المنتج لنفسه.
- دعم كمية إنتاج الدفعة بالآلاف (حتى 3 منازل عشرية) وحساب المواد المطلوبة حسابيًا بأعداد صحيحة لتجنب تقريب الكميات دون إذن.
- كل أمر إنتاج ManufacturingOrder يحفظ Snapshot ثابتًا لكميات المواد المطلوبة عند إنشائه، فلا تغيّر قائمة المواد لاحقًا طلبًا قديمًا.
- API إنشاء أوامر إنتاج بخاصية idempotency لكل عميل، دون أي تعديل مخزون أثناء التخطيط.
- إتمام أمر الإنتاج داخل Prisma Serializable transaction: قفل سجل الأمر، فحص رصيد المواد، خصم كل مادة من رصيد الصنف والموقع والدفعات القائمة، تسجيل حركة الاستهلاك وتزامن عروض السوق، إضافة المنتج النهائي إلى المخزون والموقع وربط الدفعة إن أدخلت، حساب التكلفة من متوسط تكلفة المواد، ثم إغلاق الأمر وتسجيل تدقيق.
- إلغاء أمر الإنتاج دون تحريك مخزون، مع سبب إلزامي وتسجيل أثر.
- واجهة /manufacturing للمالك والمدير مع إنشاء BOM وأمر إنتاج واعتماد إنتاج وإلغاء، وواجهة قراءة للمحاسب؛ إضافة الوحدة إلى مساحات العمل حسب نشاط الشركة.
- اختبار منطق الكميات والتكلفة في tests/manufacturing-math.test.mjs.

## قواعد أمان
- Owner/Manager فقط يصنع أو يغير أمرًا؛ Accountant يقرأ فقط. الشركة والمخزون والفروع لا تعبر إلى منشآت أخرى.
- لا يمكن إتمام أمر مرتين أو إنتاجه إذا كانت المواد غير كافية؛ المعاملة تعود كاملة عند فشل عنصر واحد.
- لا يجوز تطبيق النموذج على قاعدة الإنتاج قبل تنفيذ فحوص Prisma/CI ومراجعة يدوية لمخاطر التزامن والتكاليف.
- التكلفة مادية فقط؛ لا تشمل تكلفة تشغيل الماكينات والعمالة والطاقة والهدر ولا إصدار قيد مالي أو فاتورة ضريبية.
- lotNumber اختياري. لا نعلن وجود تتبع جودة رقابي أو نظام قبول إنتاج.
- لا MRP تلقائي ولا أوامر جودة ولا إدارة صيانة ماكينات ولا تتبع مراكز تكاليف، ولا WMS بمسارات رفوف متقدمة.
- API يقرأ إلى 120 BOM و150 أمر إنتاج، وواجهة المواد إلى 500 منتج؛ ترقيم الصفحات والأحمال الكبيرة مطلوبان قبل العمل المؤسسي.

- إعداد فترات المحاسبة وقيم المخزون يراجع من مختص قبل اعتماد أي قائمة مالية.

## الوحدات الأخرى التي ما زالت مطلوبة
شاشة مطبخ ومبيعات متعددة القنوات، WMS متقدم، عقود خدمات/ضمانات وOTP ميداني آمن، SSO/SCIM وتدقيق خارجي مقاوم للعبث، ربط ZATCA الرسمي وPDPL، قيد مزدوج آلي شامل وتسويات بنكية، Webhooks/WhatsApp وتكاملات التجارة الإلكترونية، اختبار أحمال مؤسسية.
