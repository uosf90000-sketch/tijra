# تسليم Git Tag لإصدار الحوكمة — تِجرا

هذه الوثيقة تُجهز إصدارًا تجريبيًا ولا تعلن جاهزية الإنتاج.

## الحالة الحالية
- مصدر التغييرات: `feat/purchase-guardian-20261023`
- طلب المراجعة: https://github.com/uosf90000-sketch/tijra/pull/40
- لم يتم دمج PR أو نشر Railway أو تشغيل ترحيل schema في الإنتاج.
- GitHub Actions ما زال يفشل ولا يوفّر سجلات خطوات واضحة، **فلا تنشئ/تدفع الوسم قبل نجاح الفحص**.
- لا توجد وسوم جديدة دُفعت نيابة عن مالك المستودع.

## مسؤولية المطور قبل الوسم
1. تشغيل `bash scripts/verify-release-candidate.sh v0.4.0-rc.1` في نسخة محلية من المستودع على نفس الفرع مع `DATABASE_URL` لبيئة اختبار فقط.
2. تأكيد نجاح GitHub Actions لهذا الالتزام، ومعالجة أي TypeScript/Prisma/Next/build/audit/test failure.
3. رفع المخطط إلى قاعدة **staging** مع نسخة احتياطية واختبار ارتداد مُجرّب (لا تستخدم db push على الإنتاج).
4. اختبارات تشغيل للشراء والبيع والرواتب والقيود والجرد وعزل الشركات وصلاحيات الفروع والحالات المتزامنة.
5. اختبار إعداد وحماية MFA_ENCRYPTION_KEY وAUDIT_EXPORT_SIGNING_KEY ونشرهما فقط في إدارة الأسرار، وعدم تسجيل أسرار أو رموز MFA في السجلات.
6. اختبارات آلية/يدوية لأرقام الفواتير المكررة وحساب الصندوق لكل فرع ومبيعات legacy بلا موقع.
7. التحقق من صلاحيات أدوار الموظف والمحاسب والمدير والمالك والمورد، ومن عدم تسريب بيانات الشركة في أي API.
8. توثيق نتائج الاختبار والمحضر والموافقات على نسخة المرشح للإصدار؛ **لا تسمه إصدار إنتاج نهائيًا**.

## أوامر دفع الوسم — ينفذها مالك المستودع بنفسه فقط بعد اجتياز البوابات

```bash
git fetch origin
git switch feat/purchase-guardian-20261023
git pull --ff-only origin feat/purchase-guardian-20261023

# استخدم قاعدة اختبار منفصلة، ولا تضع كلمة المرور في سجل الأوامر.
bash scripts/verify-release-candidate.sh v0.4.0-rc.1

# بعد نجاح CI واختبارات staging والحصول على موافقة الإصدار:
git tag -a v0.4.0-rc.1 "$(git rev-parse HEAD)" -m "Tijra governance release candidate"
git push origin v0.4.0-rc.1
```

- لا تستعمل `git push --tags` تلقائيًا لأن ذلك قد يرسل وسومًا أخرى غير مقصودة.
- تفعيل CI عند push للوسوم `v*` موجود في هذا الفرع، **ولكن CI على الوسم سيبدأ بعد دفعه، وليس بدل فحص PR/branch قبل الدفع**.
- بعد نجاح النسخة التجريبية والمراجعة والدمج المنفصل، يُنشأ وسم إصدار نهائي من التزام معتمد على main بعد موافقة مسؤول النشر.
- لتأكيد الوسوم المحلية: `git tag --list`، ولتأكيد الوسم البعيد: `git ls-remote --tags origin`.

لا يزال يلزم تدقيق صلاحيات كل API، وتطبيق مراجعات الأمن ومراقبة الأداء والتحقق من الامتثال، والتكامل المحاسبي/الضريبي، وسجل تدقيق خارجي معزول؛ هذه ليست شروطًا قابلة للتجاوز لمجرد نجاح سطر أوامر الوسم.
