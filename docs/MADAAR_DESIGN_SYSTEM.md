# مدار | Madaar — نظام التصميم الموحّد

تاريخ التطوير: 24 أكتوبر 2026. التنفيذ محفوظ في فرع `feat/purchase-guardian-20261023` ضمن PR #40 (Draft)، ولا يوجد نشر تلقائي.

## الهوية المعتمدة
- **الاسم الظاهر:** مدار، `Madaar`.
- **العبارة:** كل أعمالك في مدار واحد.
- **الألوان الأساسية:** #0C6869 فيروزي عميق، #19A78D أخضر فيروزي، #122F34 حبر، #F4F8F7 خلفية، #FFFFFF بطاقات، #E0EAE7 خطوط فصل.
- **الشعار:** علامة دوران واتصال دائرية، ملف `components/madaar-logo.tsx`. ملف `components/tijra-logo.tsx` مجرد إعادة تصدير للتوافق مع الاستيرادات الحالية؛ ليس علامتين تجاريتين.
- **المصدر:** `lib/brand.ts` لاسم المنتج ووصفه وألوانه، مع إظهار metadata وmanifest منه.
- **الأيقونة:** `app/icon.svg` لهوية Madaar في تثبيت الويب والمتصفح. هذه نسخة SVG مبسطة من الفكرة البصرية؛ اللوحة الإبداعية الأصلية صورة مرجعية ولا نعلن أنها Vector مطابقة بنسبة 100%.

## القاعدة المعمارية: نظام واحد وكل شخص واجهته
- **المالك والرئيس:** لوحة شاملة وتحليلات وفروع ونشاط وموافقات.
- **المدير:** مركز التشغيل والمهام المصرح بها.
- **الكاشير:** POS واضح وسريع، لا يجب أن تتكرر إحصاءات غير لازمة على شاشة البيع.
- **المحاسب:** الإيرادات والمصروفات والقيود والتسويات والمستحقات.
- **المشتريات/المخزون:** RFQ وطلبات ومخزون وجرد ومستودعات.
- **الموظف المقيّد:** شاشة مهمة قصيرة مع تنقل محدود حسب الأذونات والفروع.
- **المورد:** منتجاته وطلباته في الواجهة المخصصة.

**التصميم لا يمنح الصلاحيات:** الصلاحيات تُفحص على الخادم وفي API وقاعدة البيانات حسب التطبيق. إخفاء القائمة لا يكفي للتأمين.

## نظام CSS — مصدر واحد
حُفظت ملفات CSS القديمة وظيفيًا إلى حين اختبار إزالتها؛ `app/madaar-design-system.css` يستورد **آخرًا** من `app/layout.tsx` ليضبط tokens ويمنع التباين بين الشاشات. تتضمن:
1. المتغيرات `--madaar-*` مع جسور توافق إلى `--brand-*`, `--tijra-*`, `--approved-*`.
2. لوحات وSidebar وTopbar وبطاقات المؤشرات والرسوم، والجداول والنماذج وحالات التنبيه.
3. تنسيق POS وشاشات الموظف والجوال، وتدرج الحواف والأزرار.
4. اتجاه RTL العربي، خط بديل مناسب، حالات focus واضحة، وشاشات متجاوبة مع تفضيل تقليل الحركة.
5. عناوين موحدة عبر `components/page-header.tsx`.

## الضمانات والتغطية
- صفحات تسجيل الدخول والتسجيل والقوائم والبحث السريع وبيانات PWA تستخدم اسم مدار الجديد.
- إعدادات البيانات الداخلية واسم المستودع ومفاتيح الـAPI ووظائف Prisma تظل `tijra` للتوافق ومنع انقطاع الإنتاج.
- اختبار ثابت `tests/madaar-ui-brand.test.mjs` لحماية الهوية من التراجع.
- **لم تُختبر الرندرة الفعلية** على Next.js ولا على متصفحات متعددة؛ CI ما زال غير قابل للتشغيل بسبب قفل فوترة GitHub.
- لا يوجد دمج مع `main`، ولا نشر على Railway، ولا دفعة Git tags.

## معايير قبول التصميم بعد تشغيل CI
- `npm ci && npm run typecheck && npm run build && node --test tests/*.test.mjs`.
- معاينة Desktop 1440px، Tablet 768px، iPhone عرض 390px لأدوار: مالك، مدير، محاسب، كاشير، موظف مخزون، مورد.
- فحص RTL وارتفاع كل زر عملي وعرض الجداول الكبيرة والسلة وفئات المنتجات، وعدم تداخل القائمة واللوحات.
- تجربة الألوان وفق WCAG للخطوط الصغيرة وحالات focus/keyboard وتخفيف الحركة.
- مراجعة البطاقات الفارغة والتحميل والأخطاء، مع التأكد من أن التحسين البصري لم يغيّر دورة الفواتير أو قواعد الحوكمة.
- تحقق إنسان من التطابق البصري مع الشعار المصور المعتمد؛ تحسين رسم Vector إن لزم.
